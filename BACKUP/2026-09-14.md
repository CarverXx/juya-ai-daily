## 模型发布

### [书生-S2 正式版 Intern-S2-397B 开源](https://huggingface.co/internlm/Intern-S2-397B) `#2`
> 书生-S2模型正式版（Intern-S2-397B）开源上线 Hugging Face。官方称这是其面向科学智能与长程 Agent 的最强多模态基础模型，科学能力较 Preview版进一步优化。

上海人工智能实验室书生-S2 正式版模型 Intern-S2-397B 已在 Hugging Face 开源上架。据介绍，相比此前 Preview-397B，正式版进一步优化了科学能力，在长程科学任务上展现出更强的处理能力；官方称这是其目前面向科学智能与长程 Agent 能力最强的多模态基础模型。官方介绍，模型通过视觉预训练直接学习科学文献原始页面、联合训练超过 20 个领域的科学强化学习任务，并接入大规模沙盒环境进行黑盒 Agentic 强化学习，官方称其在开源模型中取得领先的通用推理表现，在生物分子相互作用设计、材料结构生成等专业科学任务上结果强劲。部署方面支持多种推理框架，也可注册官方 Intern API 直接调用。
