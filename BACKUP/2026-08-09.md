## 要闻

### [Codex 重置全部付费用户用量限制，周一将再次重置](https://x.com/thsottiaux/status/2086188036493344823) `#1`
> Codex 负责人Tibo 与Claude Code 主创Boris Cherny 因一名用户称在 Claude Code 中使用其他模型后遭封号而展开交锋。Tibo 随后重置了 ChatGPT Work 和 Codex 所有付费用户的用量限制。有用户吐槽这次重置只是“表演”，因为正常周额度刚刚刷新，Tibo 回应称将于（当地时间）周一再次重置。

近日，一名开发者称，他参考 Tibo 此前分享的方案，把 OpenAI 模型接入 Claude Code 后，Anthropic 账号很快被暂停使用。他公开申诉并向 Tibo 求助。Codex 负责人 Tibo 转发了这件事，表示自己虽然不在 Anthropic 工作，但如果用户只是用 Claude Code 的外壳运行其他模型就被封号，确实很奇怪，并询问是否还有类似情况。

Claude Code 主创 Boris Cherny 随后下场回应。他先开玩笑邀请 Tibo 去 Anthropic 工作，随后明确表示，Anthropic 并不会因为用户在 Claude Code 中使用其他模型而封禁账号，这次更可能是其他账号风控分类器被触发，团队正在调查。Boris 之后进一步说明，Claude Code 本身支持通过 LiteLLM 等工具接入其他模型，只是不同模型对应的工具设计和提示词优化并不完全通用。

事件基本解决后，Tibo 表示“harness 的自由很重要，应该让用户自己决定哪个模型最好”，同时回应 Boris 的挖角称自己不会离开 OpenAI。随后他又称，为庆祝 GPT-5.6 Sol 可以运行在 Claude Code 中，并宣布重置 ChatGPT Work 和 Codex 付费用户的使用额度。

有人吐槽这次重置只是“表演”，因为正常周额度刚刚刷新，Tibo则顺势回应称（当地时间）周一还会再来一次“表演式重置”。

### [MiniMax计划开源统一图像模型，支持文生图与通用编辑](https://mp.weixin.qq.com/s/kjwKHMy88JWPs0nn9pYFGQ) `#4`
> MiniMax计划开源一款统一图像模型，支持Text-to-Image和通用图像编辑。它和H3共享VAE Encoder，配专属Decoder，正处后训练优化阶段。

MiniMax H3技术团队本周在Reddit AMA中透露，计划开源一款统一的图像模型，同时支持Text-to-Image和通用图像编辑，目前正处在后训练优化阶段。该模型与H3共享同一基础架构谱系，沿用H3的VAE Encoder，并单独设计用于图像生成的VAE Decoder。MiniMax设想的工作流是，先用图像模型生成首帧，再交给H3继续生成视频。团队还提到，H3此前仅训练过根据首帧和文字描述预测尾帧的任务，未做专门的图像编辑训练，却在多项图像编辑评测中表现出较强的零样本能力，这正是继续扩展图像模型的重要依据。
