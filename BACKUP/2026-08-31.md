## 产品应用

### [ChatGPT 应用近期推送懒加载更新，长对话提速10倍](https://x.com/btraut/status/2094119709222519134) `#1`
> ChatGPT 桌面端近期优化了长对话的加载方式，不再一打开聊天就读取全部历史内容，而是先加载最近几轮，需要时再继续读取。工程师 Brent Traut 表示，这让长对话的加载时间和内存占用都减少了 90% 以上，新对话已经生效，旧对话之后也会逐步升级。

ChatGPT 最近优化了长对话的加载方式。过去打开一段很长的聊天记录时，应用会一次性读取此前的全部内容，对话越长，打开速度越慢，占用的内存也越多。现在改成了按需加载：进入对话时只先读取最近几轮消息，只有继续往上翻时，才加载更早的内容。负责这项改动的工程师 Brent Traut 表示，更新后长对话的加载时间和内存占用都减少了 90% 以上，打开长聊天大约可快 10 倍，从某条消息另开对话等操作也会更快。相关优化已应用到 Mac、Windows、Linux、CLI、VS Code 扩展以及基于开源 app server 构建的应用。目前新对话已经使用这套机制，旧对话之后会逐步迁移；长时间聊天时的输入卡顿等问题还在继续优化。

### [报道称OpenAI购买数万台Mac mini与Mac Studio用于Agent训练](https://www.theinformation.com/articles/apple-stumbled-ai-hardware-success-mac) `#3`
> 据报道，OpenAI 采购了数万台 Mac mini 和 Mac Studio 用于 Agent 训练。报道亦称 Anthropic 借 AWS 租赁 Mac mini，均未获确认。

据 The Information 报道，OpenAI 在过去数月内购买了数万台苹果 Mac mini 和 Mac Studio 设备，当前主要用于强化学习与计算机使用 Agent 的训练工作。这类苹果设备凭借统一内存架构以及可绕过标准 TCP/IP 网络协议栈的低延迟雷电 5 特性，被认为适合设备端 Agentic 编排。同一报道指出，Anthropic 也在通过 Amazon AWS 租赁 Mac mini 设备以优化 Agent 工作流，上述采购与租赁行为均属媒体报道，OpenAI 与 Anthropic 尚未作出正式确认。

### [报道称字节豆包2.2延期以补强编程与Agent能力](https://mp.weixin.qq.com/s/x4wUN14Lm17VwYrDBarJiQ) `#4`
> 据报道，字节豆包大模型2.2推迟发布。该模型原计划8月推出，目前因延长训练以提升编程及Agent能力而延期。

据《白鲸实验室》报道，多位接近字节跳动的人士称，原计划8月推出的豆包大模型2.2推迟面世。延期原因是内部希望用更长周期换取编程、工具调用和Agent能力的明显提升，目标是在年底前使其编程能力达到类似智谱和Kimi近期模型的行业冲击力。为此，字节加快人员调整，并在8月中旬将Seed基础模型部门重组为预训练数据、强化学习等四个一级部门，重点强化编程后训练与办公场景的Agentic能力。另外，该模型训练拒绝数据蒸馏，此前有传闻称其参数将追加至5T乃至10T。
