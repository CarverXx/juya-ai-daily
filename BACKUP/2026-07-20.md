### [Kimi 因 K3 需求激增暂停新用户订阅](https://mp.weixin.qq.com/s/EPs028Zj1DiYaOk_01-JFQ) `#3`
> 因算力紧缺，Kimi宣布暂停个人用户新订阅，已订阅用户不受影响。目前正全速扩容并分批恢复，后续订阅套餐将拆分为Kimi主权益与Kimi Code两方案。

月之暗面 Kimi 团队发布说明称，自 Kimi K3 发布后，过去 48 小时用户请求量大幅超出预估并逼近现有集群承载极限。为此，团队已暂停 C 端新用户订阅，将全部算力用于保障已订阅用户的现有权益。官方表示正在全速推进算力扩容，后续将分批开放新订阅名额直至全面恢复。对于后续新订阅用户，Kimi 计划拆分会员权益，将 Kimi 主权益（包含 Kimi Web、Kimi APP、Kimi Work）与 Kimi Code 权益分开，以便更精准匹配算力、保障用户体验。公司为体验不足向用户郑重道歉。

### [阿里云百炼上线 HappyOyster 1.0 并开启灰测](https://mp.weixin.qq.com/s/kfbpyEZ9UY6-6vFudBK2tQ) `#5`
> 阿里云百炼正式上线 HappyOyster 1.0并开启灰测。官方称该产品为全球首个主动式实时交互世界模型，支持实时交互与分支叙事。

阿里云百炼正式上线 HappyOyster 1.0 并开启灰测，官方称其为全球首个主动式实时交互世界模型。该模型学习状态转移规律，支持用户在任意节点介入改变数字世界走向，具备世界探索与实时导演两大模式。世界探索模式支持 1 分钟连续实时交互，实时导演模式支持 3 分钟以上 480p 或 720p 实时画面及分支叙事。目前产品提供 Open API 和三端 SDK，企业和开发者可借此构建可玩世界、互动剧等沉浸式应用。

### [昆仑万维发布并开源 Matrix-Game 3.5 交互世界模型](https://github.com/Riemann-Dynamics/Matrix-Game-3.5) `#6`
> 昆仑万维发布并开源 Matrix-Game 3.5 交互世界模型，目前 5B 基础模型已上线。官方称该模型在 720p 分辨率下具备 1 分钟记忆能力。

昆仑万维发布并开源 Matrix-Game 3.5 交互世界模型，目前 5B 基础模型权重及代码已在 GitHub 和 HuggingFace 上线。官方称该模型通过引入 Patch Memory 实现了摄像机可控的 720p 视频生成，5B 模型在 720p 分辨率下具备 1 分钟记忆能力，并可达成单卡 20FPS 的实时生成性能。模型分为第一人称和第三人称模式，推理需配备显存至少 40GB 的 NVIDIA GPU；开源仓库显示，当前放出的是基础双向模型，蒸馏后的实时自回归模型尚未发布。
